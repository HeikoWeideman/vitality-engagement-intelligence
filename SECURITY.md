# Security Policy

## Scope

The Vitality Engagement Intelligence Engine is a portfolio and demonstration project using fully synthetic data. It is not a production clinical system and does not authorise automated operational action.

## Reporting a security issue

Please do not disclose exploitable security issues, credentials, secrets, personal information, or sensitive data in a public issue.

For a potentially sensitive security concern, contact the repository owner privately through GitHub before publishing technical details.

## Data and credential safety

- Do not commit API keys, service-account credentials, access tokens, passwords, or private configuration.
- Do not add real personal, health, clinical, or confidential data to the repository.
- Use synthetic or appropriately non-sensitive test fixtures only.
- Review generated artifacts before committing them to ensure they contain no secrets or unintended sensitive information.

## Governance boundary

Security fixes must not bypass or weaken the project's human-review requirements, monitoring controls, subgroup protections, drift thresholds, suppression rules, or other governance safeguards.

## Supported version

Security maintenance applies to the current version of the main branch.
